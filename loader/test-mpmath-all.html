wasthon — mpmath suite dashboard

Runs mpmath 1.4.1's own test modules. mpmath is 100% pure Python, so this measures Brython rather than the C bridge -- and it is where the mpmath==1.4.1 pin came from: 1.3's py2-era exec-templated operators lose int_types under Brython. brython + the VFS load once and the modules run sequentially in one interpreter — no per-module reload. The module list is read from the VFS, so it follows whatever gen_sympy_vfs.mjs shipped. Per-module detail goes to the browser console; the page shows the table.
