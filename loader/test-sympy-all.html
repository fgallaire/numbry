wasthon — sympy suite dashboard

Runs sympy 1.14's own test modules. sympy is 100% pure Python, so this measures Brython rather than the C bridge. brython + the VFS load once and the modules run sequentially in one interpreter — no per-module reload. The module list is read from the VFS, so it follows whatever gen_sympy_vfs.mjs shipped. Per-module detail goes to the browser console; the page shows the table.
